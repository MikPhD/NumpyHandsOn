# 🧠 ML & Data Science Hands-On Exercises

Welcome! This repository contains a diverse and growing collection of practical exercises designed to **explore the building blocks of Machine Learning, Deep Learning, and Data Science** through hands-on experimentation.

Each notebook and script in this folder is the result of direct exploration — not just theory, but real code written to understand and experiment with:
- Core ML algorithms and workflows 🧮
- Neural network architectures with PyTorch & TensorFlow 🕸️
- Data preprocessing, visualization, and analysis using Pandas, NumPy, Matplotlib, Seaborn 📊
- Interactive and dynamic tools with Jupyter widgets 📈
- Unsupervised learning, clustering, UMAP, dimensionality reduction 🚀
- GNNs, custom loss functions, and novel ML components ⚙️

This is not just a showcase — it's a personal sandbox for learning, experimenting, debugging, and refining intuition across different domains of the ML stack.

---

## 📚 Structure & Philosophy

Each subfolder or notebook is:
- **Self-contained**: Clear imports, explanations, and goals.
- **Task-oriented**: Focused on a particular idea, library, or method.
- **Evolving**: May include TODOs, questions, or areas for deeper exploration.
- **Minimal or advanced** depending on the purpose — from scratch implementations to real-world datasets.
